# Kevin’s Mazes

A collection of 25 hand-drawn mazes by Kevin, redrawn as clean SVGs and interactive 3D web pages.

## Play The Big Cahuna Run

[Open the game](https://the-big-cahuna-run.the-big-cahuna-run.workers.dev) — race through Maze 24, collect prizes, and escape before time runs out. Play solo, against bots, or with up to four players in private invite rooms. Desktop quadrant views and mobile live spectating let you follow your rivals.

Source, development commands, and game rules are in [big-cahuna/README.md](big-cahuna/README.md).

## Play Maze Chase

[Open Maze Chase](https://kevins-maze-chase.the-big-cahuna-run.workers.dev) — one hunter, three runners, five original maze arenas. Collect two keys and escape, or hunt the runners using footprints and reveal pulses. Play with bots or friends in invite rooms, rotate roles over four rounds, and vote for the next arena.

Rules, controls, and development commands are in [maze-chase/README.md](maze-chase/README.md).

## Files

- **cleaned mazes/** — scalable SVG versions for viewing and printing.
- **Web Mazes/** — standalone HTML versions with interactive 3D maze walls.

## Viewing a maze

Open any HTML file in **Web Mazes** in your browser. Each page is self-contained; no installation or server is required.

Drag to rotate, scroll or pinch to zoom, and use the controls for a top view, reset, or wall-height adjustment.

Location pins mark the starts, and checkered flags mark the finishes. Mazes 24 and 25 include collectibles and scoring legends.
